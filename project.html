Project

Netwerkconfiguratie

Beschrijving

In dit project heb ik een VLAN-netwerk opgezet met routing en switching via Cisco-apparatuur. Ik heb subnetten berekend, VLANs geconfigureerd op een Cisco-switch en inter-VLAN routing ingesteld via een router.

Dit project heeft me geholpen om de praktische kant van netwerken beter te begrijpen.

Wat ik maakte

  • Subnetten berekend voor het netwerk
  • VLANs geconfigureerd op een Cisco-switch
  • Inter-VLAN routing ingesteld via een router
